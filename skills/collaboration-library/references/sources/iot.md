## 真实协议探针先于实现

第三方文档与现场行为可能不一致。

- 确认环境、账号权限与业务生命周期。
- 用最小合法请求记录脱敏响应形状。
- 以真实形状建立契约测试。
- 验证：错误测试也能全绿；以真实可追溯样本校验。
- 边界：不得把原始敏感响应、密钥或个人文件打印到公开日志。

## 生命周期幂等与状态演进

同一业务 ID 会经历开始、完成和分片等状态。

- 观察完整生命周期，确认 ID 稳定性与复用范围。
- 按业务实体、状态或版本定义去重与更新。
- 覆盖重复、乱序和签名链接变化。
- 验证：有效状态升级不能被当作重放丢弃；临时 URL 不作实体身份。
- 边界：不要无条件套用某个 ID 拼接公式。

## 接收台账与可解释丢弃

对方未发和本方丢弃表现相同。

- 合法接收后先持久化必要台账，再异步处理。
- 记录拒收、去重、降级的原因与判据。
- 对照发送方与接收方记录。
- 验证：明示台账覆盖边界，敏感数据最小化保存。
- 边界：不无条件持久化未鉴权的攻击负载。

## 时间敏感任务独立节拍

慢任务会阻塞有过期窗口的数据获取。

- 量实际执行间隔，区分优先级与迭代时长。
- 隔离时间敏感调度并加重入保护。
- 检查共享配额、状态和降级路径。
- 验证：延迟和失败恢复可测；不靠调顺序推断执行频率。
- 边界：独立计时器不是所有系统的通用实现。

## 不变量与路径细节分开

新增处理路径与旧数据库条件冲突。

- 明确成功必须成立的事实。
- 把旧路径特有字段从业务不变量中分离。
- 为真实不变量补契约检查。
- 验证：不能为了消除报错而删除数据完整性条件。
- 边界：数据库迁移另按任务授权实施。
