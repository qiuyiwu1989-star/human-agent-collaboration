## 单一真源与线上版本一致

多个副本或手工上线导致实际版本不清。

- 确认生效路径，再比较副本内容。
- 收敛权威源和生成链，版本控制运行所需产物与配置模板。
- 验证部署版本可回溯。
- 验证：不能只按文件名判断副本价值；秘密只留受控配置。
- 边界：未经授权不删除旧文件或线上资源。

## 业务结果控制队列推进

外部接口可能 HTTP 成功但业务全部失败。

- 定义业务成功和部分成功的判据。
- 只推进确认成功的条目，失败保留可重试状态。
- 覆盖无 error 字段、部分拒收和结果未知。
- 验证：测试零成功时不消费队列，部分成功不重做已成功项。
- 边界：success>0 也不能证明整批完成。

## 案例：接口没有 error 仍然整批失败

限制：不推断所有接口都使用相同字段或成功定义。
